# 吹牛骰子 + 狼人杀（可玩版）

两个不完全信息博弈游戏，各带桌面版和网页版：

- **吹牛骰子（Liar's Dice）**：两人各 5 颗骰子，只看得到自己的，轮流叫数或喊"开"
- **狼人杀（Werewolf）**：默认 7 人局，狼人×2 / 平民×2 / 女巫 / 预言家 / 猎人

两个游戏共用一套对局记录格式。桌面版用 pygame，网页版只用 Python 标准库。

> 这两个游戏来自一个关于不完全信息博弈的研究项目——研究 AI 在看不到对手手牌时如何决策。
> 本仓库放的是**能玩的版本**，研究代码、训练权重与实验数据不在仓库里。

## 桌面版

需要 Python 3.10 以上和 pygame。

```bash
pip install pygame

python liarsdice_playable/dice_gui.py     # 吹牛骰子
python werewolf_playable/werewolf_gui.py  # 狼人杀
```

Windows 也可以双击各自目录里的 `start.bat`。

**吹牛骰子**有四个对手，风格与难度不同：老实人（入门）、老江湖（进阶）、记忆师（高手）、读心者（专家）。
也可以让两个 AI 自己打、你在旁边看，支持 0.25x~8x 调速。

**狼人杀**你是村民阵营的一员，夜晚由 AI 行动（刀人、验人、用药），白天讨论后投票。

## 网页版

```bash
python web/server.py --port 8105 --host 127.0.0.1
```

然后浏览器打开 <http://localhost:8105>。

- **只需要 Python 标准库**，不用装 pygame
- 默认只监听 `127.0.0.1`，外网访问不了
- 首页右上角可以注册/登录，对局记录与成就会归到账号；不登录也能玩
- 手机浏览器自适应

### 关于"研究模型"参数

网页版有两个可选参数 `--wolf-model` / `--dice-model`，用来挂载训练好的模型档。
**这些模型文件不在本仓库里**（体积与研究数据原因），
所以直接传这两个参数启动时，程序会检测到缺文件，打印原因并退出——这是预期行为。

不传这两个参数时，AI 使用内置的启发式策略，功能完整、开箱即用。

## 关于素材

`assets/` 里只有**界面图片和音效**。

**背景音乐没有入库**（版权与体积原因）。要音乐的话，把音频按 `bgm_1.mp3` ~ `bgm_5.wav`
命名放进 `assets/` 即可，曲目表在 `gui_common.py` 的 `MUSIC_TRACKS`（可自行修改）。

缺音乐时游戏正常运行，只是没有背景音乐（`Music` 类里有异常兜底）。

## 对局记录

每打完一局，自动往 `对局记录/<游戏>/年-月-日.jsonl` 追加一行。
一行就是完整的一局：时间、seed、双方是谁、每一步的动作、最后谁赢、开盅时双方的手牌。
格式说明见《记录格式说明.md》。

记录只写在本机，不上传。网页版结算页有"下载本局记录"可以自己存一份。

## 说明

- 桌面版不联网、不开端口；网页版默认只监听本机。
- AI 对战会跨局记忆（记住了你上一局怎么叫），同一个 seed 能复现发牌，但不保证复现后面每一步的选择。
- 难度是玩法标签，不是精确胜率；真人完全可能赢。
