网页版（端口 8105）
==================

启动
----
在本目录运行：

    python server.py --port 8105 --host 127.0.0.1

然后浏览器打开 http://localhost:8105

服务端**只用 Python 标准库**，不需要 pygame、不需要 npm、不需要构建。

参数
----
--port        端口，默认 8105
--host        监听地址，默认 127.0.0.1（只有本机能访问）
              改成 0.0.0.0 可让同一局域网的其他设备访问（自担风险）
--record-root 对局记录写到哪，默认 ../对局记录

说明
----
· 默认只监听 127.0.0.1，外网访问不了。
· 两个游戏的人机对战、AI 内战、暂停/调速、记录都可用。
· 中途退出：点顶栏「退出本局」，会先写一行 aborted=true 的未完成记录再回设置页；
  直接关页面或刷新也会尽量兜底。
· AI 不是秒回：骰子约 1.5 秒（显示「对手正在想」），狼人杀约 1.8 秒/步。
· 骰子开盅是逐颗揭晓（约 0.32 秒/颗），1 是百搭时百搭颗会单独高亮，揭完才显示胜负。
· 首页右上角「设置」：音乐开关/音量、对局记录自动下载、清空记录（仅本机可用的三个选项）。
· 背景音乐不入库；自行把音频放进上一级的 assets/，命名 bgm_1.mp3 ~ bgm_5.wav。
· 记录双份：主机一定写一份到「对局记录/」；玩家可在结算页点「下载本局记录」自己存一份，
  登录账号后首页「导出我的记录」会把该账号的记录打包成 zip。
· 账号：首页右上角注册/登录（cookie，HttpOnly + SameSite=Lax）。
  账号库是本机 SQLite（用户数据/users.db），只存本地，不上传。
· 手机浏览器自适应：390×844 / 360×640 实测；狼人杀在手机上改成座位网格，不挤椭圆桌。
· 成就只显示名称与解锁日期，未解锁显示 ???；解锁时屏幕上方弹 3 秒提示，不显示条件。

目录
----
server.py          HTTP 服务与路由
user_db.py         本地账号库（SQLite）
achievements.py    成就判定
static/            前端页面（原生 HTML/CSS/JS）
