# 狼人杀 · 多发言实验档 —— 使用说明

> 这份说明只讲**多发言实验档**（一天能说好几句）。
> 原来的三选一玩法和 `start.bat` 一个字都没动，想玩原版直接双击 `start.bat`。

---

## 一、这是什么东西

默认那版，一个人一天只能说**一句**（沉默 / 我是 X / 我认为 X 是 Y）。
这个实验档，一个人一天最多能说**三条**：**1 条自报 + 2 条指认**。

**它是个玩法实验档，不是研究结论。** 研究那边已经明确测过：话变多了，但投票和认人的准头没动（LRS_083）。
所以这里**不许**说"多发言让 AI 变强"——没有这回事。

---

## 二、怎么启动

### 情况一：你拿到的是压缩包（免安装版）

解压后，里面有**两个**双击就能开的：

| 双击这个 | 玩的是 |
|---|---|
| `开始狼人杀.bat` | **原版**（一天一句） |
| `开始狼人杀_多发言.bat` | **多发言实验档**（一天最多三条） |

免安装包**自带 Python**，不用装任何东西。

### 情况二：你在源码目录里（开发/研究环境）

| 双击这个 | 玩的是 |
|---|---|
| `start.bat` | **原版**（一天一句） |
| `start_多发言实验.bat` | **多发言实验档** |

**不需要联网，不会开任何端口，也不会装东西。**

- 窗口开起来就是对应的档，不用再去菜单里找开关。
- 多发言档**只能用启发式 AI**：研究模型在这里被**明确关掉**了（练模型时看的东西和现在对不上，
  硬接会给出没意义的结果）。所以「AI 对手」按钮在这个档里点了也不会生效。

### 如果双击没反应

免安装包：确认解压完整（`Werewolf` 文件夹要和 bat 放在一起）。

源码目录：先确认这台机器上装了 Python 和 `pygame`；
2. 或者直接用原版 `start.bat`——它会自己找可用的 Python。

---

## 三、一天怎么说话（操作）

轮到你了，屏幕会先清屏（"请把设备交给某人"），按「我准备好了」。

到发言阶段，你会看到一个发言面板：

```
本次发言（最多 3 条，0/3）
（还没有内容；直接点「结束发言」就是沉默）

[我是 X（自报）]

[结束发言]  [撤销最后一条]  [清空]
```

**推荐的顺序：**

1. 点 **「我是 X（自报）」** → 选一个身份（狼人 / 平民 / 女巫 / 预言家 / 猎人）。
   这一条**一天只能有一条**。
2. 点 **目标座位**（比如 `2·小满`）→ 再点 **「他是 Y」**（你认为他是什么身份）。
   这就攒了一条指认。**同一个目标一天只能指一次**（不会让你重复说同一个人）。
3. 想再说一个人，就再点另一个座位 → 再选身份。总共**最多指两个人**。
4. 点 **「结束发言」** → 环境会**按顺序逐条执行**你攒的所有发言，然后进入投票。

**几个按钮：**

| 按钮 | 作用 |
|---|---|
| 结束发言 | 提交整段话，逐条执行。**一条都没有就等于沉默。** |
| 撤销最后一条 | 删掉刚攒的最后一条（可以连按） |
| 清空 | 把攒的全部删掉，等于重新来 |

**规则限制（环境强制，不是界面提示）：**

- 一天最多 **1 条自报 + 2 条指认**，合计不超过 3 条；
- 不能指自己，不能指已经死的人；
- 同一个目标不能指两次；
- 空序列 = 沉默。

如果你攒到 3 条，面板会显示「已达 3 条上限」，这时只能结束、撤销或清空。

## 四、已知限制（请先看这几条）

1. **只能 7 人局。** 板子是固定的：狼人 2、平民 2、女巫 1、预言家 1、猎人 1。
2. **研究模型不参与。** 这个档只跑启发式 AI（代码里叫 baseline 3/4）。
   想用研究模型请回默认档（`开始狼人杀.bat` / `start.bat`）。
3. **免安装包自带 Python，不用装环境**；源码目录方式需要本机有 Python + pygame。
4. **不能只拷源码目录里的 `werewolf_playable` 这一个文件夹。** 它要用上一层的
   `gui_common.py`、`profile.py` 和 `assets/`。要搬就**整个 `对外游戏` 文件夹一起搬**。
   （免安装包不受这条限制——它是独立打包的。）
5. **人机交互没做自动化点击测试。** 自动测过的是：窗口能开、整局能跑完、能退出。
   鼠标点的细节请你亲手试一局，有问题告诉我。
6. **记录格式有一点点不同**：多发言档的记录里，每条发言会多一个"这是本座今天第几句"的编号；
   旧记录没有这个字段，照样能读。

### 关于"会不会卡住"

早先有一份内部记录说"多发言档连着跑第 3 局会卡死"，**那个说法是错的，已经查明并撤销**。

真实情况：一局要跑多久，取决于这一局里发生多少次行动——**每个行动等 0.9 秒**。
所以一局 30 秒、45 秒、60 秒都正常，纯看你打了多少个回合。当时看起来"卡住"，
其实是**跑得慢、检查的人等不及把程序关掉了**。

实测：连跑 30 局（3 轮 × 10 局）全部正常。**你可以放心连着玩。**

## 五、打完之后记录在哪

- **免安装包**：解压目录下的 `对局记录\werewolf\年-月-日.jsonl`
- **源码目录**：`对外游戏\对局记录\werewolf\年-月-日.jsonl`

多发言档会比原版多记这些：

- 每条发言的**顺序号**（第几句）；
- 整局用了哪个档（`speech_mode`）、当天每人说了什么（`speech_seq`）、一共说了多少条（`n_speech`）。

旧的记录文件不用改，程序会自动当它是"三选一"档。

详细字段说明见同目录的 `记录格式说明.md` 第八节。

---

## 六、一句话总结

**双击多发言那个 bat → 攒几条发言 → 结束 → 看 AI 怎么接。**
这只是玩法扩展，不是"AI 变强了"。
